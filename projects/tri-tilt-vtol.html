1. 80-Page AustroControl SORA SAIL II Certification

Search and Rescue missions in Alpine Austrian terrain present severe operational ground risks. I authored an extensive 80-page Technical Design Document (TDD) adhering to EASA SORA (Specific Operations Risk Assessment) regulations.

  • Ground Risk Class (GRC) 3 mitigation with autonomous dual-line parachute deployment.
  • Hardware-isolated failure mode & effects analysis (FMEA) for all power distribution paths.
  • Fail-safe geofencing and automatic return-to-home (RTH) upon loss of telemetry > 1.5 seconds.

2. Hardware Dual-Battery Failover Latching Circuitry

To guarantee zero voltage dip during high-current battery cell degradation or thermal shutdown, I engineered a high-side P-channel MOS-FET fast switching circuit. Switching latency is bounded to strictly under 5 microseconds, preserving flight controller CPU state during live flight.

// Smooth Cosine Transition Interpolator for Tri-Tilt Rotor Servos
void TriTiltRotorController::updateTransitionMatrix(float alpha) {
    const float alphaRad = std::clamp(alpha, 0.0f, 1.0f) * M_PI_2;
    const float liftRatio = std::cos(alphaRad);
    const float thrustRatio = std::sin(alphaRad);

    _leftTiltServo.setAngle(alpha * 90.0f);
    _rightTiltServo.setAngle(alpha * 90.0f);

    // Dynamically reweight PID mixer matrices between multicopter and fixed-wing mode
    _multicopterAttitudeController.setMixerWeights(liftRatio);
    _fixedWingElevonController.setMixerWeights(thrustRatio);
}
