1. Zero-Dependency Quaternion Rigid Body Dynamics

Unlike conventional physics engines that rely on Euler angles prone to gimbal lock during vertical VTOL flight phases, I implemented quaternion orientation dynamics ($q = [w, x, y, z]$). All matrix math is vectorized using Eigen C++ templates.

2. 4th-Order Runge-Kutta (RK4) Numerical Integration

// RK4 Integration Step
State6DoF PhysicsEngine::integrateRK4(const State6DoF& s, float dt) {
    Derivative k1 = computeDerivatives(s, 0.0f);
    Derivative k2 = computeDerivatives(s + k1 * (dt * 0.5f), dt * 0.5f);
    Derivative k3 = computeDerivatives(s + k2 * (dt * 0.5f), dt * 0.5f);
    Derivative k4 = computeDerivatives(s + k3 * dt, dt);

    Derivative dState = (k1 + (k2 * 2.0f) + (k3 * 2.0f) + k4) * (1.0f / 6.0f);
    return s + dState * dt;
}
